ALCHAMENTRY WEBSITE SHOWCASE

Files
- alchamentry-site-showcase.html: responsive, self-contained homepage concept. The primary logo and flask icon are embedded as SVG data URIs, so they remain available when the HTML is moved.
- alchamentry-logo-outlined.svg: primary light-background vector lockup.
- alchamentry-logo-dark-outlined.svg: dark-background vector lockup.
- alchamentry-icon.svg: standalone flask symbol.
- alchamentry-logo-mono.svg: monochrome logo variant.

Theme tokens used in the HTML
- Paper / page background: #F8FAFC
- White surface: #FFFFFF
- Primary ink: #101828
- Deep navy: #0B1220
- Body text: #536176
- Quiet text: #7C899C
- Borders: #E3E8F0
- Cobalt: #315FF5
- Violet: #9857E8
- Pink: #DB63C4
- Warm coral: #F96E99
- Orange: #FF914F
- Amber: #FFD16A

Typography
- Inter: headings, navigation, product cards, and body copy.
- DM Mono: labels, index numbers, and metadata.
- Google Fonts are linked externally; system fallback fonts are included for offline use.

Design notes
- Cool, low-contrast surfaces provide a calm canvas for the detailed flask mark.
- Brand gradients are used as accents rather than large backgrounds.
- Dark navy is reserved for the principles section and closing CTA.
- Responsive layout, mobile navigation, reduced-motion support, skip link, and visible keyboard focus states are included.

This is a homepage concept built from the existing Alchamentry website content. Review all product descriptions and external links before deploying it as the live site.
